# WCAG 2.2 and WAI Easy Checks

- Author: W3C Web Accessibility Initiative
- Year: WCAG 2.2 W3C Recommendation, edition of 12 December 2024; Easy Checks (current page)
- Legal URLs: https://www.w3.org/TR/WCAG22/ ; https://www.w3.org/WAI/test-evaluate/preliminary/

## What I read

The WCAG 2.2 list of new criteria, the removal of 4.1.1, and the level A and AA criteria up to 2.5 (thresholds for contrast, reflow, text spacing); the whole Easy Checks page.

## Key lessons used in exploratory/accessibility-testing.md

- New in 2.2 at A and AA: 2.4.11 Focus Not Obscured (Minimum), 2.5.7 Dragging Movements, 2.5.8 Target Size (Minimum) 24 by 24 CSS px, 3.2.6 Consistent Help, 3.3.7 Redundant Entry, 3.3.8 Accessible Authentication (Minimum). 4.1.1 Parsing removed.
- Thresholds: 4.5:1 text, 3:1 large text and non text; reflow at 320 CSS px; text spacing 1.5, 2, 0.12, 0.16.
- Easy Checks: page title, alt text, headings, contrast, text resize to 200 percent, keyboard access and visible focus, forms labels and errors, moving and flashing content, multimedia alternatives, basic structure. "Not definitive": passing them does not mean accessible.

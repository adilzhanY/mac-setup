# On the Relation of Test Smells to Software Code Quality

- Authors: Davide Spadini, Fabio Palomba, Andy Zaidman, Magiel Bruntink, Alberto Bacchelli
- Year: 2018 (ICSME 2018)
- Legal URL: https://zenodo.org/record/1689875 (author's preprint); also https://pure.tudelft.nl/ws/files/46651094/main.pdf

## What I read

Abstract, introduction and the summary of results. Not the full statistical sections.

## Key lessons used in quality/test-smells.md

- 221 releases of 10 systems, over a million test cases, 6 smells.
- Smelly tests are more change prone and more defect prone.
- Indirect Testing, Eager Test and Assertion Roulette were the most significant smells for change proneness.
- Production code tested by smelly tests is more defect prone, so smells are not only a style issue.

## Key lessons used in web/accessibility-testing.md

- Primary desktop: JAWS 40.5%, NVDA 37.7%, VoiceOver 9.7%, Orca 2.4%.
- Any use: NVDA 65.6%, JAWS 60.5%, VoiceOver 43.9%; mobile VoiceOver 70.6%, TalkBack 34.7%.
- Top pairs: JAWS + Chrome 24.7%, NVDA + Chrome 21.3%, JAWS + Edge 11.4%, NVDA + Firefox 10.0%, VoiceOver + Safari 7.0%.
- 71.6% find information on long pages by headings first. Self selected sample.

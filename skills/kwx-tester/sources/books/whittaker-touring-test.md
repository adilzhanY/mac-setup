# The touring test (blog) and the books How to Break Software / Exploratory Software Testing

- Author: James Whittaker
- Year: blog post 12 February 2009 (Microsoft, archived on Microsoft Learn); books 2002 and 2009 (not read, paid)
- Legal URL: https://learn.microsoft.com/en-us/archive/blogs/james_whittaker/the-touring-test

## What I read

The full blog post. The books were not read; the attack list in heuristics.md is recalled from the 2002 book's table of contents and marked as such.

## Key lessons used in exploratory/heuristics.md

- Software as components, features and capabilities; tours as focused, purposeful routes through them (tourism metaphor).
- Tours named: Supermodel (surface only), Money (what sales demos), Intellectual (hard questions), Garbage collector's, Competitor's, Museum, After hours, FedEx (follow data), Prior version, Guidebook, Saboteur, TOGOF, Rained out (timing).
- Tours give testers a shared vocabulary of test concepts, above individual test cases.

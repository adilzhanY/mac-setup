# What we found when we tested tools on the world's least-accessible webpage

- Author: Mehmet Duran, GDS Accessibility team
- Year: 2017 (24 February); results page updated 13 April 2018
- Legal URL: https://accessibility.blog.gov.uk/2017/02/24/what-we-found-when-we-tested-tools-on-the-worlds-least-accessible-webpage/ ; https://alphagov.github.io/accessibility-tool-audit/

## What I read

The blog post and the results page.

## Key lessons used in web/accessibility-testing.md, web/web.md

- 2017: 143 barriers in 19 categories, 10 free tools; tools together found 71%; 29% missed by all; best single tool 37% (Tenon), 41% with manual prompts (Asqatasun); worst 17%.
- 2018 results page: 142 barriers, 13 tools; SortSite 40%, axe 29%, WAVE 30%, lowest 13%.
- Tools 'cannot be relied on, by themselves'; combine with manual checking, audits and user testing.

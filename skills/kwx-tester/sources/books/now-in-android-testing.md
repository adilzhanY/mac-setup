# Now in Android (reference app), testing setup

- Authors: Android team at Google
- Year: maintained continuously (read 2026-10-31)
- Legal URL: https://github.com/android/nowinandroid (README, Apache 2.0)

## What I read

The README sections on build variants, testing, screenshot tests and baseline profiles.

## Key lessons used in mobile/android-native.md (also mobile/mobile.md)

- No mocking libraries: test doubles implement the production interfaces and are swapped in with Hilt test APIs; "less brittle tests that may exercise more production code".
- A `demo` flavor with static local data for development and deterministic UI tests; `demoRelease` for UI performance work.
- Run variant tasks (`testDemoDebug`, `connectedDemoDebugAndroidTest`), not the global `test` or `connectedAndroidTest`.
- Screenshot tests with Roborazzi: `recordRoborazziDemoDebug` and `verifyRoborazziDemoDebug`; other platforms render slightly differently, so record on one platform.
- Baseline profiles regenerate whenever startup code changes; generated by running the `BaselineProfileGenerator` test on an AOSP emulator.

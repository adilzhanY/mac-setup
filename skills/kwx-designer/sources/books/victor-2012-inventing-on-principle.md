# Bret Victor (2012), Inventing on Principle (talk)

- **Citation:** Bret Victor, "Inventing on Principle", talk at CUSEC 2012 (Canadian University Software Engineering Conference). Video freely published by the conference.
- **Copy read:** transcript published at jamesclear.com/great-speeches/inventing-on-principle-by-bret-victor.
- **Used in:** `editors/canvas-and-direct-manipulation.md`.

## Principle

Creators need an immediate connection to what they create. Any change should show its effect at once; delay and hidden state make the creator "design blind", and "there is this whole world of ideas which will just never be" when the loop is broken.

## Demos and what each teaches for editors

- **Live code beside a drawn scene:** dragging a number in the code updates the picture live; this revealed an idea (a shimmer suggesting wind) that typing would never have found. Rule: draggable numbers with live canvas update.
- **Platform game with time:** instead of replaying, show the future trajectory as a trail while tuning a jump. "You need to be able to see across time." Rule: onion skins, motion paths, previews across time.
- **Binary search with values shown:** show concrete data for each step instead of making the user "play computer" in their head. Rule: show intermediate results.
- **Circuit with live waveforms:** "Show the data. Show comparisons." Rule: hover-to-compare previews.
- **Performed animation on an iPad:** motion recorded by hand instead of keyframed, in about two minutes. Rule: let users perform values when the value is a motion.

## Lesson for the skill

Never require Apply for anything that can be previewed; expose hidden state and time.

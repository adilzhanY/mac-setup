# Visual foundations and web reading list

Sources read on 2026-10-27 for `visual/*` and `platforms/web/*`. "Read" means fetched and studied; "via search" means only the search summary was available (page blocked or JS-only), so treat those claims as weaker.

## Official store rules

- Apple, Marketing Resources and Identity Guidelines (badges, wording, device images, legal lines): https://developer.apple.com/app-store/marketing/guidelines/ (read)
- Apple, Offering apps and games for pre-order: https://developer.apple.com/app-store/pre-orders/ (read)
- Apple, App Store marketing toolbox (badges, links, QR): https://toolbox.marketingtools.apple.com/app-store/
- Apple, Smart App Banners: https://developer.apple.com/documentation/webkit/promoting-apps-with-smart-app-banners (JS page, syntax from known spec)
- Google, Partner Marketing Hub, lockups, icons and badges: https://partnermarketinghub.withgoogle.com/brands/google-play/google-play/lockups-icons-badges/ (read)
- Google, badge guidelines text shipped with the artwork (mirrored in nextcloud/server LICENSES/LicenseRef-GooglePlayBadge.txt): https://raw.githubusercontent.com/nextcloud/server/master/LICENSES/LicenseRef-GooglePlayBadge.txt (read)
- Google Play badge redirect: https://play.google.com/intl/en_us/badges/

## Typography

- Matthew Butterick, Practical Typography: summary of key rules, typography in ten minutes, line length, line spacing, headings, letterspacing: https://practicaltypography.com (read)
- Richard Rutter, The Elements of Typographic Style Applied to the Web: https://webtypography.net/toc/, 2.1.2 measure, 2.2.2 vertical rhythm, 3.1.1 scale (read)
- Utopia, Designing with fluid type scales: https://utopia.fyi/blog/designing-with-fluid-type-scales/ (read)
- MDN, font-optical-sizing: https://developer.mozilla.org/en-US/docs/Web/CSS/font-optical-sizing (read)
- Typekit, Type study: pairing typefaces: https://blog.typekit.com/2012/05/23/type-study-pairing-typefaces/ (read)
- Google Fonts Knowledge, Pairing typefaces within a family and superfamily: https://fonts.google.com/knowledge/choosing_type/pairing_typefaces_within_a_family_superfamily (JS only, via search)
- Josh Comeau, The surprising truth about pixels and accessibility: https://www.joshwcomeau.com/css/surprising-truth-about-pixels-and-accessibility/ (read)
